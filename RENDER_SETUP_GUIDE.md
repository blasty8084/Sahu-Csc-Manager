# SAHU CSC — Render Deployment Guide

> **What Render hosts:** Backend API only (`artifacts/api-server`)
> **Frontend** goes on Vercel separately — see `VERCEL_SETUP_GUIDE.md`

---

## Overview

```
GitHub Repo
    │
    ├── Render (Backend API)   →  https://sahu-csc-api.onrender.com
    └── Vercel (Frontend)      →  https://your-app.vercel.app
                                         │
                              /api/* proxied to Render
```

## Method 1 — Auto Setup (Blueprint) ✅ Recommended

`render.yaml` is already in the repo. Render reads it automatically and configures everything.

### Step 1 — Connect GitHub

1. Go to [render.com](https://render.com) → **Get Started for Free**
2. Sign up / log in with GitHub
3. Click **New +** → **Blueprint**
4. Select your GitHub repo → click **Connect**
5. Render reads `render.yaml` and shows a preview of what it will create

### Step 2 — Fill in Secret Variables

Render will show a form for all `sync: false` variables. Fill these in:

| Variable | Value |
|---|---|
| `DATABASE_URL` | Your Neon PostgreSQL URL (from neon.tech) |
| `ADMIN_PASSWORD` | Strong password for admin account |
| `OPERATOR_PASSWORD` | Strong password for operator account |
| `SMTP_USER` | your-email@gmail.com |
| `SMTP_PASS` | Gmail App Password |
| `SMTP_FROM_EMAIL` | `SAHU CSC <your-email@gmail.com>` |
| `VAPID_EMAIL` | `mailto:your-email@gmail.com` |

> `SESSION_SECRET` is auto-generated by Render — you don't need to fill it in.

### Step 3 — Apply Schema & Seed Database

After first deploy completes, open:
**Render Dashboard → your service → Shell tab**

```bash
# Apply database schema
node -e "
const { execSync } = require('child_process');
execSync('npx drizzle-kit push --force', { stdio: 'inherit', cwd: '/opt/render/project/src' });
"
```

Then seed admin/operator accounts:
```bash
node dist/scripts/seed.mjs
```

### Step 4 — Update CORS

After Vercel deploy, come back to Render:
**Dashboard → service → Environment → Edit** `CORS_ORIGIN`

```
CORS_ORIGIN=https://your-app.vercel.app
```

Click **Save Changes** — Render auto-redeploys.

## Method 2 — Manual Setup

### Step 1 — Create Web Service

1. [render.com](https://render.com) → **New +** → **Web Service**
2. Connect your GitHub repo
3. Fill in the service settings:

| Setting | Value |
|---|---|
| **Name** | `sahu-csc-api` |
| **Region** | Singapore (closest to India) |
| **Branch** | `main` |
| **Root Directory** | *(leave blank)* |
| **Runtime** | Node |
| **Build Command** | see below |
| **Start Command** | see below |
| **Plan** | Free |

**Build Command:**
```bash
cd artifacts/api-server && npm install -g pnpm@10 && cd ../.. && pnpm install --frozen-lockfile && pnpm --filter @workspace/api-server run build
```

**Start Command:**
```bash
node --enable-source-maps artifacts/api-server/dist/index.mjs
```

**Health Check Path:** `/api/health`

### Step 2 — Add Environment Variables

**Dashboard → service → Environment → Add Environment Variable**

Add every variable from `render.env` (in this repo). Quick reference:

#### Required (must set before deploy)

| Variable | Value |
|---|---|
| `NODE_ENV` | `production` |
| `PORT` | `10000` |
| `DATABASE_URL` | `postgresql://...` from neon.tech |
| `SESSION_SECRET` | Run `openssl rand -base64 48` to generate |
| `ADMIN_PASSWORD` | Your chosen admin password |
| `OPERATOR_PASSWORD` | Your chosen operator password |
| `CORS_ORIGIN` | `https://your-app.vercel.app` |
| `CACHE_BACKEND` | `memory` |
| `ALLOW_NON_INDIA` | `true` |
| `DISABLE_2FA` | `false` |
| `VAPID_EMAIL` | `mailto:your-email@gmail.com` |

#### Required for Email (OTP & notifications)

| Variable | Value |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | `your-email@gmail.com` |
| `SMTP_PASS` | Gmail App Password |
| `SMTP_FROM_EMAIL` | `SAHU CSC <your-email@gmail.com>` |

#### Business Info

| Variable | Value |
|---|---|
| `BUSINESS_NAME` | `SAHU CSC Center` |
| `BUSINESS_ADDRESS` | `Main Road, Bargarh, Odisha 768028` |
| `ADMIN_MOBILE` | `9876543210` |
| `OPERATOR_MOBILE` | `9876543211` |

### Step 3 — Deploy

Click **Create Web Service**. Render runs the build command and starts the server.

Check logs: **Dashboard → service → Logs tab**

Look for:
```
Server listening  port: 8080
```

### Step 4 — Apply Schema & Seed

In **Shell tab:**
```bash
node dist/scripts/seed.mjs
```

## After First Deploy — Important Steps

### Copy Auto-Generated Keys

The server generates these at first boot and stores them in the database.
**Copy them out and save as Render env vars** — otherwise a re-deploy regenerates them and breaks encrypted data and push notifications.

**Shell tab:**
```bash
node -e "
const { Pool } = require('pg');
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
pool.query(\"SELECT key, value FROM settings WHERE key IN ('encryptionKeyBase64','jwtSecret','vapidPrivateKey')\")
  .then(r => { r.rows.forEach(row => console.log(row.key + '=' + row.value)); pool.end(); });
"
```

Then add to Render Environment:

| Variable | Source |
|---|---|
| `ENCRYPTION_KEY` | value of `encryptionKeyBase64` from above |
| `JWT_SECRET` | value of `jwtSecret` from above |
| `VAPID_PRIVATE_KEY` | value of `vapidPrivateKey` from above |

### Update CORS After Vercel Deploy

```
CORS_ORIGIN=https://your-actual-vercel-url.vercel.app
```

## Auto-Deploy (GitHub → Render)

```bash
git push origin main
# Render redeploys in ~2-3 minutes
```

## Optional Services

### Backblaze B2 (cloud storage for avatars & backups)
Without this, avatars are stored as base64 in the DB and backups are local only.
```
B2_KEY_ID=
B2_APP_KEY=
B2_BUCKET_NAME=sahu-csc-storage
B2_BUCKET_ENDPOINT=https://s3.us-west-004.backblazeb2.com
```

### Upstash Redis (background jobs)
Enables the Worker Server for scheduled tasks via BullMQ.
```
REDIS_URL=rediss://default:password@host:port
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=
CACHE_BACKEND=redis
```

### Sentry (error tracking)
```
SENTRY_DSN=https://xxx@sentry.io/xxx
```

### MaxMind GeoIP
Enables accurate India-only geo restriction. Free key at maxmind.com.
```
MAXMIND_LICENSE_KEY=
ALLOW_NON_INDIA=false
```

## Troubleshooting

| Problem | Fix |
|---|---|
| Build fails — `pnpm not found` | Check build command includes `npm install -g pnpm@10` |
| `relation "settings" does not exist` | Schema not pushed — run `drizzle-kit push` in Shell tab |
| Login says invalid credentials | Run `node dist/scripts/seed.mjs` in Shell tab |
| CORS error in browser | Set `CORS_ORIGIN` to your exact Vercel URL on Render |
| Server sleeps after 15 min | Free tier limitation — upgrade to Starter plan or use UptimeRobot to ping `/api/health` every 10 min |
| Encrypted data unreadable after redeploy | `ENCRYPTION_KEY` not set — copy from DB settings table (see above) |
| Push notifications stop working | `VAPID_PRIVATE_KEY` not set — copy from DB settings table (see above) |

## Free Tier Limits

| Limit | Value |
|---|---|
| Sleep after inactivity | 15 minutes |
| Monthly hours | 750 hrs (enough for one service) |
| RAM | 512 MB |
| Build minutes | 500/month |

> **Tip:** Use [UptimeRobot](https://uptimerobot.com) (free) to ping `/api/health` every 10 minutes and prevent the server from sleeping.
